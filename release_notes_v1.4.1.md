## CrackSegmentation 1.4.1

### Fixed in 1.4.1

- **User manual**: the manual panel could stay blank (grey) and pressing **Manual** / **?** again did not bring the photo back. Now any problem displaying the manual is written in the panel, the second press always returns to the photo, and PDF pages with padded rows are read correctly.

Includes everything new in 1.4.0: **Edit extremes** (key **4**), hiding a crack's markers with a click, and **Hide uncertain overlay** / **Hide normal overlay**.

### Downloads

- **macOS (Apple Silicon)**: `CrackSegmentation-1.4.1-macos-arm64.dmg`. Not notarized by Apple: on first launch, open **System Settings → Privacy & Security** and click **Open Anyway** (only needed once).
- **Windows**: `CrackSegmentation-1.4.1-windows-Setup.exe`, or the portable `CrackSegmentation-1.4.1-windows-portable.zip`. Unsigned: if SmartScreen flags it, click **More info → Run anyway**.
- **Linux (Debian/Ubuntu, amd64)**: `cracksegmentation_1.4.1_amd64.deb`. Install with `sudo apt install ./cracksegmentation_1.4.1_amd64.deb`.
- **Linux (other distributions, amd64)**: `CrackSegmentation-1.4.1-linux-x86_64.tar.gz`. Portable, no package manager required: extract it and run `./CrackSegmentation/CrackSegmentation`.
